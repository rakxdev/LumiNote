Contributions

Contributions are welcome. Read CONTRIBUTING.md before opening a pull request — in short:

  1. Run the verification gates (check:fast after edits, check:task before handing back) — tests must pass, ratchets must hold.
  2. One logical change per commit, described honestly in English.
  3. Respect CONSTRAINTS.md — never weaken the bar to make a change pass.

# Code of Conduct

## The short version

Be decent. This is a small personal project — review feedback, issues, and
discussions should stay technical, honest, and kind.

## Expected behavior

- Critique code and ideas, not people.
- Assume competence and good intent; ask before assuming bad faith.
- Keep discussions in English so the maintainer can follow everything.
- Respect that the maintainer may decline features that don't fit the
  product's direction (personal-first, no accounts, vanilla stack).

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Trolling, bad-faith arguments, or publishing others' private information.
- Sexualized language or imagery anywhere in the project's spaces.

## Enforcement

The maintainer (rakxdev) may edit or remove comments, issues, and pull
requests that violate this document, and may block repeat offenders.
Report problems through a GitHub issue or direct message to
[@rakxdev](https://github.com/rakxdev).

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/) — credit for
the widely used structure belongs to its authors.

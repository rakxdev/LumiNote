# LumiNote: Product Context

## The Problem
Speech transcription tools are either clunky batch uploaders or sluggish voice recorders that force users to wait or lock the text box during live transcription.

## The Solution: LumiNote
LumiNote is a high-speed, browser-native AI dictation studio. It combines real-time streaming speech models (AssemblyAI v3 & Deepgram Nova-3) with an interactive transcript editor where users can edit, fix, and format words in real-time *while* speaking.

## Target User & Context
- Founders, creators, writers, and power users dictating notes, essays, drafts, or prompts in a dark-mode focused environment.
- Single-page zero-latency workstation that runs effortlessly on both desktop and mobile.

## Primary Surface: Dictation Studio (Operate Mode)
- Single-screen zero-scroll lock (`100dvh`).
- Live waveform / VU reactivity.
- Seamless editing with tactile controls (Clear, Copy, Export, Fix Grammar, Record).

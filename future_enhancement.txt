[FEATURE PROPOSAL]
Feature Name: Cross-Device Real-Time Relay Network (PIN & QR Code Pairing)
Status: Planned / Future Feature

-------------------------------------------------------------------
1. OVERVIEW & USER CONCEPT
-------------------------------------------------------------------
A seamless bi-directional relay network allowing a user to pair their Desktop/Laptop browser with a Mobile smartphone using a short 6-digit PIN code (or QR code scan).

Key Benefits:
- Smartphone acts as a wireless HD microphone & pocket recorder.
- Desktop acts as the primary big-screen display, editor, and copy hub.
- Live speech transcription recorded on mobile streams in real-time (<50ms relay latency) directly onto the laptop screen.
- Bi-directional clipboard sync & text editing (edit on desktop -> updates phone; copy on phone -> updates laptop).

-------------------------------------------------------------------
2. ARCHITECTURAL & TECHNICAL BLUEPRINT
-------------------------------------------------------------------
A. Device Pairing Protocol:
   1. Desktop opens LumiNote -> Clicks "Pair Mobile Device".
   2. Server/Relay generates a unique room ID & short PIN (e.g. 784-291) + QR code.
   3. Desktop subscribes to WebSocket channel `room_784291`.
   4. Mobile phone scans QR code or enters PIN -> joins `room_784291`.
   5. Both devices show "🟢 Paired & Connected" status badge.

B. Data & Stream Relay Pipeline:
   - Mobile Audio Stream / Transcript Chunks -> WebSocket Relay -> Desktop Display Engine.
   - Cross-device sync over Cloudflare Durable Objects / WebSockets or WebRTC P2P DataChannels.

C. Target Use Cases:
   - Wireless microphone for lectures, meetings, and roaming presentations.
   - Instant cross-device copy & paste buffer.
   - Multi-screen collaborative editing.
